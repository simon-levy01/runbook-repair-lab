# Studio

Standalone Sanity Studio for the Runbook Repair Lab structured fictional content.

Install with `npm ci`, typecheck with `npx tsc --noEmit`, run with `npm run dev`.
Use the project owner's normal browser sign-in after ownership claim.
Keep `.env.local`, project write keys and claim links out of source and browser bundles.
The public Next.js app is in `../web` and needs no credential.
